# Rimu Coachworks

The Rimu Coachworks website, published on Tiiny Host from this repository.

- `index.html` is the whole page.
- `images/` holds the photos and logos it uses.
- `huckleberry/index.html` is the Huckleberry Harvester House site, served at rimucoachworks.com/huckleberry/.
  Its "Visit Huckleberry Harvester" card on the home page links there (`LINKS` in index.html).
  Inquiries, "Find a time" and Provisions questions go to commissions@rimucoachworks.com until Huckleberry
  has its own inbox, Calendly and Shopify store.
